# step4.0.1 ECR 리포지토리 만들기

3단계까지 이미지는 Docker Hub(`sujeong79/bus-*:step2.3`)에 있었다. 4단계는 WSL(개발) · EC2 kubeadm(검증) · EKS(운영)가 같은 이미지를 쓰도록 ECR 에 저장소를 만든다.

| 실행 | 위치 | 하는 일 |
|---|---|---|
| `bash infra/step4/install-aws-cli.sh` | WSL | AWS CLI v2 설치, Windows `~/.aws` 를 가리키게 (키 복사 없음) |
| `bash infra/step4/ecr/create-repos.sh` | WSL | `bus-app` · `bus-web` 생성 (있으면 설정만 맞춤) |

| 설정 | 값 | 이유 |
|---|---|---|
| 태그 변경 | IMMUTABLE | 같은 태그 재 push 거절 → 검증한 태그 = 운영 이미지 |
| 스캔 | push 할 때 (기본 스캔) | OS 패키지 CVE 를 push 마다 확인 (4.0.2 에서 결과) |
| 암호화 | AES256 | 기본값을 드러냄 |
| 수명 주기 | 태그 없는 이미지 1일 · 최근 10개 | 저장 요금 (GB당) 을 작게 |
| 태그 | Project=bus-capstone | 4.9 정리 때 찾기 |

계정 ID 는 비밀 값으로 다룬다 — 스크립트는 `****1234` 처럼 뒤 4자리만 보여 준다. 콘솔 스크린샷에서도 가린다.
리포지토리 이름 = 이미지 이름이라, 매니페스트에서는 `sujeong79/bus-app` → `<계정>.dkr.ecr.ap-northeast-2.amazonaws.com/bus-app` 으로 앞부분만 바뀐다 (4.0.3 overlay `images.newName`).
