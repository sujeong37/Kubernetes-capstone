# step4.4 데이터 유지 (EKS · EBS)

`bash infra/step4/eks/data-test.sh` (WSL, `STEP=1|2|3` 으로 하나만)

| 단계 | 하는 일 | 볼 것 |
|---|---|---|
| 준비 | ALB 로 즐겨찾기 등록 + 별칭 「4.4 시험 시각」 | db Pod · 노드 · 영역 · EBS 볼륨 ID |
| ① app Pod 교체 | `kubectl rollout restart deploy/app` | 별칭 그대로 · ALB 실패 0 (preStop · 등록 해제 30초 · PDB) |
| ② db Pod 교체 | `kubectl delete pod` (DB 1개 · Recreate) | 별칭 그대로 · 같은 EBS · 잠깐 실패 (단일 DB 의 한계 → 4.5 RDS) |
| ③ 노드 교체 | db 노드의 NodeClaim 삭제 → Auto Mode 가 drain · 새 노드 | 별칭 그대로 · **같은 EBS 볼륨 · 같은 영역** (3.4 local-path 는 cordon 하면 Pending 이던 한계) |

그동안 백그라운드로 0.5초마다 ALB `/api/favorites` 를 불러 실패 수를 센다.
