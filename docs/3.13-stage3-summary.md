# ③ Kubernetes 전환 — 정리 (stage3-k8s)

EC2 3대(cp .10 · worker1 .11 · worker2 .12, Rocky 9, t3.medium) + kubeadm v1.36 + Calico(IPIP) 위에 버스 도착 정보 앱(web · app · db)을 올렸다.
최종 점검: `bash k8s/step3/check.sh` (cp, 읽기만 함) · 적용: `kubectl apply -k k8s/step3` · Git 과 비교: `kubectl diff -k k8s/step3`

```
내 PC ─┬─ :30080 (NodePort) ─→ web ×2 (Nginx) ─ /api ─→ app ×2 (FastAPI) ─→ db ×1 (MySQL 8.4 + PVC local-path)
       └─ :30133 (Gateway)  ─→ Envoy ×2 ─┬─ /api → app ×2                       ↑ NetworkPolicy: db 는 app 에서만
                                          └─ /    → web ×2
```

## 4단계로 넘길 것

| 3단계 한계 | 4단계 |
|---|---|
| db 1개 · local-path (노드 하나에 묶임, cordon 하면 Pending) | RDS 전환 |
| Secret 을 손으로 만듦 | Secrets Manager + Pod Identity |
| NodePort (내 IP 만, 노드 IP 가 재기동마다 바뀜) | ALB (Gateway/Ingress) |
| Docker Hub 이미지 | ECR (overlay 의 images 한 줄) |
| 노드를 직접 관리 (kubeadm · CSR 승인 · 재기동) | EKS Auto Mode |
