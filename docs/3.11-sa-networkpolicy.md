# step3.11 전용 ServiceAccount · NetworkPolicy

## ServiceAccount

| | 전 (default SA) | 후 (app · web 전용 SA) |
|---|---|---|
| Pod 안 API 토큰 | `/var/run/secrets/kubernetes.io/serviceaccount/token` 자동 마운트 | 없음 (`automountServiceAccountToken: false`) |
| 권한 (RBAC) | default SA — 바인딩 없음 | 바인딩 없음 = 0 |
| 뜻 | 앱이 털리면 토큰으로 API 를 두드려 볼 수 있다 | 자격 증명 자체가 없다 |

db 는 바꾸지 않았다 (Recreate 라 바꾸는 순간 DB 가 잠깐 멈춘다 — 4단계 RDS 전환 때 정리).

## NetworkPolicy (Calico 가 구현)

| 정책 | 대상 | 허용 |
|---|---|---|
| default-deny-ingress | bus 의 모든 Pod | 없음 (기본 거부) |
| db-from-app | db | app Pod → 3306 |
| app-from-web-and-gateway | app | web Pod · envoy-gateway-system → 8000 |
| web-from-anywhere | web | 누구나 → 8080 (NodePort · Gateway 입구) |

- 노드(kubelet)의 Probe 는 NetworkPolicy 와 관계없이 허용된다.
- egress 는 열어 둔다 (app → TAGO 인터넷 · DNS).
- 3.4 「DB 는 클러스터 안에서만」 → 3.11 「DB 는 app 에서만」 으로 좁힘.
