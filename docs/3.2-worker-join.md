# step3.2 worker 노드 조인

수업 Kubernetes Core 03장 01(조인의 신뢰 수립과 kubelet 인증서) · 02(worker 노드 조인)를 따른다. 예전 클러스터 흔적이 남은 worker는 03장 03(노드 제거와 재조인)의 `kubeadm reset` + `/etc/cni/net.d` 정리로 먼저 비운다 (reset은 CNI 설정을 지우지 않는다 — 3.1에서 겪은 문제).

| 항목 | 방법 | 이유 |
|---|---|---|
| 조인 토큰 | `kubeadm token create --ttl 2h --print-join-command`, PowerShell 변수 `$JOIN` 에만 | 토큰은 비밀값. 수명을 짧게, 파일 · Notion · GitHub에 남기지 않음 |
| CA 해시 | ca.crt 공개 키 SHA-256을 직접 계산해 조인 명령 값과 비교 | 노드가 가짜 cp에 연결되지 않게 하는 검증 |
| CSR | 클라이언트(자동 승인) vs 서빙(수동). 요청자(`system:node:cp` · `worker1`)만 골라 승인, worker2는 이름으로 하나 | 서빙 인증서는 노드 이름 · IP를 클러스터가 검증할 수 없어 관리자가 확인 |
| 확인 | worker에는 kubelet.conf · ca.crt만(CA 개인 키 없음), kube-proxy DaemonSet 3개, cp만 control-plane label · taint | |
| 끝 | 토큰 모두 삭제, stop/start 후 같은 상태 | 새로 붙을 수 있는 토큰 0개 |
