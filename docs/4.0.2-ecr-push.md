# step4.0.2 WSL → ECR push

| 실행 (WSL) | 하는 일 |
|---|---|
| `bash infra/step4/ecr/push-images.sh` | 태그 결정 → ECR 로그인 → linux/amd64 빌드 → push → 플랫폼 · 사용자 · 크기 · 스캔 결과 |
| `bash infra/step4/ecr/immutable-test.sh` | 같은 태그에 내용이 다른 이미지를 push → 거절되는지, 원래 digest 가 그대로인지 |

## 태그
`git log -1 --format=%h -- app/was app/web` = 소스를 마지막으로 바꾼 커밋 (지금 `aaa4404` — 2.3 이미지 크기 개선).
2단계 Docker Hub 의 `step2.3-aaa4404` 와 같은 소스다. HEAD 가 아니라 소스 기준이라, 문서만 바뀐 커밋에서는 태그가 그대로고 이미 ECR 에 있으면 건너뛴다.
빌드 재료에 커밋하지 않은 변경이 있으면 멈춘다.

## Docker Hub(2단계) → ECR(4단계)

| | Docker Hub | ECR |
|---|---|---|
| 주소 | sujeong79/bus-*:step2.3 | `<계정>.dkr.ecr.ap-northeast-2.amazonaws.com/bus-*:aaa4404` |
| 로그인 | Docker Hub 토큰 | `aws ecr get-login-password` (IAM, 12시간) |
| 같은 태그 재 push | 덮어씀 | 거절 (IMMUTABLE) |
| 스캔 | — | push 때 자동 (OS 패키지 CVE) |
| EKS 에서 받기 | 공개 저장소 / 레이트 리밋 | 노드 역할 정책으로 같은 계정 · 리전에서 |

계정 ID 는 출력에서 `****1234` 로 가린다.
