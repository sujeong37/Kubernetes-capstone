# step3.4 외부 서비스 준비 — Amazon RDS for MySQL · TAGO 실제 키

IOT 참고 프로젝트의 3.5(AWS 서비스 준비)에 해당한다. 1 ~ 2.4단계에서 로컬 대체물로 돌리던 것을 실제 서비스로 바꾸고,
클러스터는 건드리지 않은 채 3.5(원시 매니페스트 배포)에서 앱이 붙을 자리와 최소 권한 자격 증명을 준비한다.

| 1 ~ 2.4 (로컬) | 3.4 (실제) | 역할 |
|---|---|---|
| mysql:8.4 컨테이너 + 볼륨 bus-db-data | Amazon RDS for MySQL 8.4 `bus-step3-db` (db.t4g.micro, gp3 20GB, 암호화, 공개 접근 없음, 노드와 같은 AZ) | 즐겨찾기 저장 |
| `MYSQL_USER=bus` + grants.sql로 권한 축소 | 마스터 `admin`은 초기화에만, 앱은 `bus`(SELECT · INSERT · UPDATE · DELETE만) | 앱 자격 증명 |
| 컨테이너 네트워크 안에서만 | 보안 그룹 `bus-step3-db-sg`: 3306을 노드 보안 그룹에서만 | 접근 경로 |
| 가짜 데이터 (키 없음) | TAGO 실제 키 (1-5에서 확인한 Decoding 키) | 정류장 · 도착 정보 |
| 셸 환경 변수 | 레포 밖 `~\.bus-step3\bus.env`(Windows, 본인만) → cp `~/.bus-step3/bus.env`(600) | 비밀값 |

## 왜 클러스터 안 MySQL이 아니라 RDS인가

- 3단계(kubeadm) → 4단계(EKS)로 클러스터를 바꿔도 데이터는 그대로 (IOT가 DynamoDB를 클러스터 밖에 둔 것과 같은 구조).
- 백업 · 패치 · 디스크를 관리형 서비스에 맡기고, 클러스터는 상태 없는 app · web만 돌린다.
- 클러스터 안 DB의 PVC · 노드 고정 문제는 3.6(스토리지)에서 검증 결과 보관으로 따로 다룬다.

## 만들기 (PowerShell, 순서대로 — Runbook 3.4 참고)

1. 노드에서 VPC · 노드 보안 그룹 · 서브넷 · AZ를 읽는다.
2. DB 서브넷 그룹은 AZ 2개가 필요 → 다른 AZ에 비공개 서브넷 `192.168.57.0/24`(bus-step3-db-c) 추가.
3. `bus-step3-db` 서브넷 그룹, `bus-step3-db-sg`(3306 ← 노드 SG).
4. 비밀번호 2개(admin · bus)를 RandomNumberGenerator로 만들어 `~\.bus-step3\bus.env`에 저장(icacls 본인만).
5. `aws rds create-db-instance ... --no-publicly-accessible --availability-zone <노드 AZ> --backup-retention-period 0 --storage-encrypted --db-name busdb`
   → `aws rds wait db-instance-available`.
6. cp로 bus.env 복사(600, CRLF 제거) → TAGO 키를 `read -rs`로 추가.
7. cp에서 admin으로 `init.sql`(favorites 테이블) · `bus` 계정(4권한) 생성.

## 확인 · 막혀야 할 것

| 시험 | 기대 |
|---|---|
| cp → RDS (admin) | 8.4.x, `require_secure_transport` 0 (RDS 8.4 기본값 OFF — VPC 안 통신) |
| bus로 등록 · 조회 · 삭제 | 성공 |
| bus로 `CREATE TABLE` | ERROR 1142 — 사용자 표시 `'bus'@'192.168.56.10'` (노드 IP) |
| 틀린 비밀번호 | ERROR 1045 |
| 내 PC → RDS 3306 | 이름은 사설 IP로 풀리지만 연결 실패 (공개 접근 없음 · SG) |
| Pod → RDS 3306 | 성공 — Calico IP pool `natOutgoing: true`라 Pod 패킷이 노드 IP로 바뀌어 SG(노드 SG 허용)를 통과 |
| cp → TAGO | resultCode 00, 정류장 목록 |

## 요금

- db.t4g.micro + gp3 20GB. 쓰지 않을 때 `aws rds stop-db-instance` (7일 뒤 자동 시작되므로 그 전에 다시 정지).
- 발표 후: 인스턴스(`--skip-final-snapshot`) → 서브넷 그룹 → 보안 그룹 → 서브넷 순서로 지운 뒤 수업 `delete-cluster.ps1`.
