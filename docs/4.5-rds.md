# step4.5 (선택) DB 를 Amazon RDS for MySQL 로

4.4 ② 에서 본 한계 — DB 가 Pod 1개라 교체 동안 끊기고, EBS 는 한 영역에만 붙는다 — 를 관리형 DB 로 넘긴다.
앱 이미지 · 매니페스트는 그대로, **바뀌는 값은 DB 주소 하나**.

| 순서 | 명령 (WSL) | 하는 일 |
|---|---|---|
| 1 | `bash infra/step4/rds/create-rds.sh` | 보안 그룹(3306 ← EKS 클러스터 보안 그룹만) · DB 서브넷 그룹(사설 2a · 2b) · RDS MySQL 8.4 (db.t4g.micro · gp3 20GiB · 암호화 · 공개 접근 없음) |
| 2 | `bash infra/step4/rds/migrate-rds.sh` | 클러스터 안 mysql 클라이언트 Pod 로 표 · 앱 계정 bus(4권한) 만들기, 클러스터 db → RDS 데이터 옮기기 |
| 3 | `OVERLAY=eks-rds bash infra/step4/eks/apply-eks.sh --compare` | 4.3 overlay 와의 차이 (DB_HOST · wait-db · db replicas 0) |
| 4 | `OVERLAY=eks-rds bash infra/step4/eks/apply-eks.sh` | 적용 → app 롤링 → ALB healthz |
| 5 | `bash infra/step4/rds/rds-test.sh` | 옮긴 데이터 · app Pod 교체 · RDS 재부팅 동안 실패 수 |
| 되돌리기 | `bash infra/step4/eks/apply-eks.sh` | overlay eks → db 1개 · DB_HOST=db (옮긴 뒤 바뀐 데이터는 클러스터 db 에 없다) |
| 지우기 | `bash infra/step4/rds/delete-rds.sh` | 인스턴스(스냅샷 없이) → 서브넷 그룹 → 보안 그룹. **EKS 클러스터보다 먼저** (4.9) |

## overlay `k8s/overlays/eks-rds` (base = `k8s/overlays/eks`)

| 패치 | 4.3 (클러스터 db) | 4.5 (RDS) | 이유 |
|---|---|---|---|
| ConfigMap `DB_HOST` | `db` | RDS 주소 (`RDS_HOST` 자리, 실행 때 채움) | 앱은 환경 변수로만 DB 를 찾는다 (1단계부터) |
| app init container | `nc -z db 3306` | `nc -z <RDS 주소> 3306` | 3.5 에서 db 이름을 적어 둠. Pod 템플릿이 바뀌어 롤링도 일어난다 |
| db Deployment | replicas 1 | 0 | apply 는 빠진 객체를 지우지 않는다 → 0 으로 적어 Git = 클러스터. PVC(EBS)는 되돌리기용으로 남김 |

그대로인 것: 계정 `bus` · 비밀번호(Secret `bus-db`) · 포트 · DB 이름 · 이미지 · NetworkPolicy(나가는 길은 막지 않음).

## 보안

- RDS 는 사설 서브넷 · 공개 접근 없음 · 보안 그룹은 EKS 클러스터 보안 그룹(= Auto Mode 노드, Pod 는 노드 ENI 로 나간다)에서만 3306.
- admin 비밀번호는 무작위 24자, `~/.bus-step4/bus.env`(600) 에만. `create-db-instance` 에 명령줄 인자가 아니라 600 임시 파일(`--cli-input-json`)로 넘긴다.
- 앱 계정 `bus` 는 SELECT · INSERT · UPDATE · DELETE 만 (CREATE TABLE → ERROR 1142).
- TLS: RDS for MySQL 8.4 기본값 `require_secure_transport=0`. VPC 안 통신이며 앱(PyMySQL)은 TLS 를 켜지 않았다 — 켜려면 앱 코드에 ssl 인자(이미지 다시 빌드)와 파라미터 그룹 `require_secure_transport=1` (남은 과제).

## 요금 (서울, 대략)

db.t4g.micro 시간당 약 $0.03 + gp3 20GiB 월 약 $2.6 + 자동 백업(1일, 저장 크기만큼 무료). 쓰지 않을 때 `aws rds stop-db-instance` (7일 뒤 자동 시작).
